## 使用约定

1. **写入时机**：技术路线决策经评审定案后（需求文档 DR 表 + 修订记录落档），同步在本目录追加/修订对应条目——只搬"上下文与理由"，不复制验收指标（指标以 FR 为准）。
2. **变更同步**：DR 表与 decisions.md 一一对应；需求文档修订记录出现新决策时，本目录同轮更新，不留只在对话里的理由（AGENTS.md §5）。
3. **格式**：每条决策 = 状态（定案/已关闭/待验证）+ 决策 + 上下文 + 否决项（含否决原因）+ 后果/约束 + 关联编号。禁止只写结论不写理由——结论会过时，理由才会被复用。
4. **禁止**：在本目录发明新决策。想法先走评审，定案后再进这里。
